# ShelfServe

A Home Assistant OS add-on for storing recipes, planning meals, and generating supermarket-sorted shopping lists.

## Features

- Recipe storage with uploaded images, servings, tags, ingredients, and steps.
- Breakfast, lunch, and dinner planning by week.
- Structured UK units: g, kg, ml, l, tsp, tbsp, item, and pack.
- Per-supermarket aisle ordering.
- In-app shopping checklists grouped by aisle.
- SQLite database and uploaded media stored under the add-on `/data` volume.

## Installation

Add this GitHub repository to the Home Assistant add-on store, install **ShelfServe**, then open it through the add-on's **Open Web UI** button.
